# 프로젝트 결정 사항

## 문서 목적

대화에서 확정한 방향을 기록합니다. 다른 계획 문서와 내용이 충돌하면 이 문서를 우선합니다.

## 2026-06-02 결정

### 발표와 일정

- 졸업 발표에서 프로젝트를 직접 시연하지 않습니다.
- 개발 일정 문서는 관리하지 않습니다.
- 작업은 GitHub Issue와 Pull Request 단위로 관리합니다.

### 금융상품 데이터

- 금융감독원 `금융상품 한눈에` Open API를 우선 사용합니다.
- 은행 권역 코드 `020000`의 예금·적금 상품을 요청 시점에 조회합니다.
- 제1금융권 중 지정 시중은행과 인터넷전문은행만 노출합니다.
- 특수은행, 외국계 은행 국내 지점, 저축은행 권역 코드 `030300`은 제외합니다.
- API 응답은 메모리에서 정규화하고 비교·추천에 사용합니다.
- 금융감독원 API 원문과 정규화 결과는 DB나 Git에 영구 저장하지 않습니다.
- 금융감독원 API 인증키는 개인 유형으로 신청합니다.

### MySQL과 인증

- MySQL은 MVP에서 실제 사용합니다.
- Docker 없이 프로젝트 전용 로컬 MySQL을 `127.0.0.1:3307`에서 실행합니다.
- 로그인·회원가입 기능을 MVP에 포함합니다.
- 사용자 계정, 앱 메타데이터, AI 프롬프트 버전만 저장합니다.

### AI API

- AI 제공자는 OpenAI API로 확정합니다.
- 추천 순위는 서버의 규칙 기반 점수로 결정합니다.
- OpenAI API는 추천 이유 설명과 상품 비교 요약을 우선 담당합니다.
- OpenAI API 호출은 백엔드에서만 수행하며 키는 환경 변수로만 관리합니다.
- OpenAI API 실제 요청 도달과 오류 fallback은 확인했습니다.
- OpenAI API 설명 보조 성공 응답은 결제 또는 사용 가능 크레딧 설정 후 재검증합니다.
- 결제 또는 크레딧 설정 전까지 로컬 환경에서는 OpenAI 설명 보조 호출을 비활성화합니다.

### GitHub

- 졸업 프로젝트 PPT 파일은 GitHub 저장소에 포함하지 않습니다.
- 팀원 GitHub 사용자명은 협업 시작 시 추가합니다.

## 2026-06-03 결정

### 금융상품 데이터 노출 범위 변경

- 지방은행은 상품 노출 범위에서 제외합니다.
- 시중은행은 KB국민은행, 신한은행, 우리은행, 하나은행, SC제일은행, 한국씨티은행만 포함합니다.
- 인터넷전문은행은 케이뱅크, 카카오뱅크, 토스뱅크를 포함합니다.

## 아직 필요한 확인

- OpenAI API 프로젝트의 결제 또는 사용 가능 크레딧 설정
- OpenAI API 설명 보조 성공 응답 재검증
- 협업 시작 시 팀원 GitHub 사용자명 확인
