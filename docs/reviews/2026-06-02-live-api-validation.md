예금·적금 응답을 확인했다.

- 금융감독원 API 정상 응답을 확인했다.
- 예금·적금 정규화와 허용 은행 필터가 정상 동작했다.
- API 표기에 맞춰 `주식회사 하나은행` 별칭을 허용 목록에 추가했다.
- 특수은행 예시가 필터 후 노출되지 않는 것을 확인했다.

## OpenAI API

새 OpenAI API 키를 로컬 `.env`에만 설정하고 `gpt-5.4-mini` Responses API 요청을
최소 호출로 확인했다.

- 요청은 OpenAI API 서버까지 도달했다.
- 응답은 HTTP `429`, 오류 코드 `insufficient_quota`였다.
- 애플리케이션은 오류 시 규칙 기반 기본 설명으로 정상 fallback 했다.
- 키 값은 로그, 문서, Git 대상 파일에 기록하지 않았다.

설명 보조 성공 응답을 검증하려면 OpenAI API 프로젝트에 결제 또는 사용 가능 크레딧을
설정한 뒤 다시 요청한다.

그전까지 로컬 `.env`의 `OPENAI_EXPLANATIONS_ENABLED=false`로 OpenAI 호출을 비활성화한다.
OpenAI 호출 없이 금융감독원 실데이터 조회, MySQL health, 상품 추천과 규칙 기반 비교 요약이
정상 동작하는 것을 확인했다.
