# npm 보안 점검

## 적용 내용

- Next.js를 `16.2.7`로 갱신했습니다.
- `npm audit fix`로 호환 가능한 전이 의존성 갱신을 적용했습니다.
- `npm run lint`와 `npm run build`를 통과했습니다.

## 남은 항목

`npm audit` 기준 high 취약점은 `0`건이며 moderate 취약점은 `7`건입니다.
남은 항목은 Prisma 개발 의존성, Next.js 내부 PostCSS, NextAuth의 UUID 전이 의존성입니다.

`npm audit fix --force`가 제안하는 변경은 Prisma, Next.js, NextAuth의 호환되지 않는
주 버전 변경 또는 다운그레이드이므로 적용하지 않았습니다. 후속 패키지 릴리스에서
호환 가능한 수정 버전이 제공되면 다시 점검합니다.
