# 제한형 알파테스트 검증

## 테스트 범위

같은 네트워크의 팀원이 접속하는 제한형 알파테스트를 진행했다.

- 프론트엔드: Next.js production 서버, LAN 바인딩
- 백엔드: FastAPI, 로컬 바인딩
- 데이터베이스: 프로젝트 전용 로컬 MySQL
- 금융상품: 금융감독원 실데이터
- OpenAI 설명 보조: 비활성화

## 확인한 항목

- LAN 주소에서 공개 페이지와 회원가입 페이지 접근
- NextAuth 인증 엔드포인트 접근
- 비로그인 사용자의 보호 페이지 접근 시 `/login` 리다이렉트
- 금융감독원 실데이터 상품 조회
- MySQL 연결

## 발견한 문제와 수정

회원가입 성공 후 세션이 없는 상태에서 `/home`으로 이동하여 로그인 화면으로 다시
리다이렉트되는 흐름을 수정했다. 회원가입 성공 후에는 `/login`으로 이동한다.

로그인 성공 후에는 클라이언트 라우터 이동 대신 새 문서 요청으로 `/home`을 열도록
수정했다. 인증 쿠키가 반영된 요청으로 보호 페이지를 다시 확인할 수 있다.

## 재검증

- 프론트엔드 lint 통과
- Next.js production build 통과
- 로컬 주소 로그인 세션 생성과 `/home` 접근 통과
- LAN 주소 로그인 세션 생성과 `/home` 접근 통과
- 임시 검증 계정 삭제
- 알파테스트 프론트엔드와 백엔드 서버 종료

사용자가 알파테스트 중 생성한 계정은 임의로 삭제하지 않고 보존했다.
